# Dendrita

Dendrita es una plataforma de coordinación clínica interdisciplinaria para la gestión de pacientes hospitalizados.

La información de un paciente existe, pero está fragmentada entre la ficha de cada profesión, notas manuales y traspasos de turno verbales, lo que genera omisiones, indicaciones contradictorias y deterioros detectados tarde.

Dendrita integra la ficha clínica existente con registros por voz estructurados de cada profesional en una versión única del paciente, trazable por autor y origen de cada dato. Detecta contraindicaciones no advertidas, pacientes sin evaluación y exámenes pendientes con su responsable; gestiona indicaciones contradictorias mediante consenso registrado; y estima la criticidad de cada paciente.
